# PawHome – Pet Adoption Website 

## Project Description
PawHome is a pet adoption website. The main purpose of this website is to help users find pets available for adoption and submit adoption applications online.

The website also includes an admin dashboard to manage pet information and adoption applications.

## Installation Guide
To run this website locally:

1. Download or clone this GitHub repository.
2. Install XAMPP if you haven't.
3. Move the project folder into `C:\xampp\htdocs`.
4. Open XAMPP and start Apache and MySQL.
5. Open `http://localhost/phpmyadmin`.
6. Import the provided SQL database file into phpMyAdmin.
7. Make sure the database connection in `db.php` is correct.
8. Open `http://localhost/WEB-DEV-AS1/index.php` in your browser.

## Features and Usage
**For Users:**
- Browse pets available for adoption.
- Search and filter pets.
- View pet details.
- Fill in and submit adoption forms.
- Contact PawHome through the website.

**For Admin:**
- Log in to the admin dashboard.
- Add, edit and delete pet information.
- View and manage adoption applications.
